# ComfyUI-CDToolSets

ComfyUI 自定义工具节点集合，目前提供 **QwenImage2.1提示词增强(API)**，用于通过大语言模型扩写和优化文生图、图生图提示词。

## 安装

1. 将 `ComfyUI-CDToolSets` 文件夹放入 `ComfyUI/custom_nodes/`。
2. 重启 ComfyUI。
3. 搜索 **QwenImage2.1提示词增强(API)**，或在 `CDToolSets/提示词` 分类中添加节点。

需要可用的 API 服务、API Key 和模型名称。节点无需加载本地语言模型，使用的 Python 依赖为 `requests`、`numpy` 和 `Pillow`。

## QwenImage2.1提示词增强(API)

将简短的画面需求整理为更完整的提示词，补充主体、构图、场景、光线、材质等视觉描述；图生图模式结合参考图片描述修改目标和需要保留的内容。

- 支持文生图与图生图两种任务模式。
- 支持最多 8 路参考图片输入。
- 支持中文和英文输出，要求画面文字、品牌名和专有名词保留原文。
- 支持 `/chat/completions` 和 `/responses` 两种 API 接口。
- 支持思考强度选择，并自动控制是否启用思考。
- 输出纯文本提示词，可连接到文本编码或文本显示节点。

### 参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 输入提示词 | 空 | 描述想生成的画面或对参考图片的修改要求。为空时直接输出空字符串。 |
| 任务模式 | 文生图 | 文生图用于扩写画面描述；图生图结合参考图片增强编辑指令，至少需要连接一张图片。 |
| 输出语言 | 中文 | 可选中文、英文。中文要求使用简体中文；画面中明确要求的文字、专有名词和品牌名保留原文。 |
| api_key | `local` | 所用 API 服务的密钥，必须填写。默认值用于本地服务，远程服务请填写实际密钥。 |
| api_base_url | `http://127.0.0.1:11434/v1` | API 服务地址，可根据所用服务修改，支持基础地址、以 `/v1` 结尾的地址或完整接口地址。 |
| API接口 | `/chat/completions` | 可选 `/chat/completions` 或 `/responses`，节点自动使用对应的请求格式。 |
| model | `qwen3.8-27b` | API 模型名称，以所用服务提供的名称为准。图生图需要使用支持图片输入的模型。 |
| 思考强度 | `none` | 可选 `none`、`low`、`medium`、`high`、`xhigh`、`max`。`none` 关闭思考，其余选项开启思考。 |
| seed | `0` | 仅用于 ComfyUI 判断是否重新执行节点，不发送给 API 后端。改变 seed 可触发重新生成；支持生成后固定、递增、递减或随机化。 |

### 图片输入与输出

| 接口 | 类型 | 说明 |
| --- | --- | --- |
| 图片、图片2～图片8 | `IMAGE` | 可选参考图片，仅图生图模式使用，按接口顺序发送。每个接口读取图片批次的第一张。 |
| 增强提示词 | `STRING` | 增强后的提示词文本，自动清理支持格式的思考块和代码块，并提取 JSON 回复中的 `rewritten_prompt`。 |

参考图片发送前会保持宽高比，将最长边超过 2048 像素的图片缩小到 2048 像素，并转换为 JPEG。

### 使用方法

**文生图**

1. 填写 `api_key`、`api_base_url` 和 `model`，选择服务支持的 API 接口。
2. 任务模式选择“文生图”，填写画面需求。
3. 选择输出语言和思考强度，将“增强提示词”连接到后续文本节点并执行。

输入示例：

> 一只橘猫坐在窗边，午后的阳光，温暖的生活摄影风格。

**图生图**

1. 任务模式选择“图生图”，使用支持图片输入的 API 模型。
2. 连接至少一张参考图片，可通过其他图片接口添加参考图。
3. 在输入提示词中说明修改目标、参考图的用途以及需要保留的内容。

输入示例：

> 保留图1人物的面部特征和服装，将背景替换为图2中的街道，调整为傍晚暖色光线。

### API 地址示例

以 `/chat/completions` 为例：

| api_base_url | 实际请求地址 |
| --- | --- |
| `https://api.example.com` | `https://api.example.com/v1/chat/completions` |
| `https://api.example.com/v1` | `https://api.example.com/v1/chat/completions` |
| `https://api.example.com/v1/responses` | `https://api.example.com/v1/chat/completions` |

选择 `/responses` 时使用对应路径；填写完整接口地址时，末尾接口路径会按当前选择替换。

### 使用说明

- API 服务及模型需支持所选接口，以及请求中的 `enable_thinking` 和 `reasoning_effort` 参数。各模型支持的思考强度可能不同。
- 最大输出 token 和上下文长度使用服务端默认设置。
- 节点执行时会将输入提示词发送到所填 API 地址，图生图还会发送参考图片。费用和数据处理方式以 API 服务商说明为准。
- 分享工作流前请清空 `api_key`。

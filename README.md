# ComfyUI-CDToolSets

ComfyUI 自定义工具集合，提供通用提示词生成、Qwen Image 2.1 提示词增强和顶部工具栏管理。

## 安装

1. 将 `ComfyUI-CDToolSets` 文件夹放入 `ComfyUI/custom_nodes/`。
2. 重启 ComfyUI。
3. 搜索 **通用提示词生成器(API)** 或 **QwenImage2.1提示词增强(API)**，也可在 `CDToolSets/提示词` 分类中添加节点。

提示词增强需要可用的 API 服务、API Key 和模型名称，无需加载本地语言模型，使用的 Python 依赖为 `requests`、`numpy` 和 `Pillow`。工具栏管理无需配置 API。

## 顶部工具栏管理

管理其他插件添加到 ComfyUI 工具栏中的按钮和组件，例如 Manager 按钮组、Image Feed 和 CPU/RAM/GPU 等资源监控项。

1. 点击工具栏中的 **工具栏管理**，或通过主菜单 **CDToolSets → 顶部工具栏管理** 打开面板。
2. 取消勾选需要隐藏的元素，修改立即生效；重新勾选即可撤销隐藏。
3. 可搜索元素、重新扫描，或点击 **恢复全部显示** 清除全部隐藏规则。

- 识别传统插件工具栏及新版扩展操作按钮区域，支持插件延迟加载、元素重新渲染后继续应用规则。
- 隐藏配置保存在当前浏览器，刷新后保留，不随工作流保存或导出。
- 只控制显示，不停用插件，也不影响按钮原有操作。撤销隐藏不会强制显示被原插件自身设置关闭的元素。
- 管理入口不参与隐藏；暂时未检测到的元素会保留其隐藏规则，可在面板中清除。
- 无标题的元素使用图标、样式类或文字作为标识；插件更改元素标识后可能需要重新配置。工具栏区域之外的侧栏、浮窗和画布按钮不在管理范围内。

## 通用提示词生成器(API)

通过选择任务模式，把用户输入和该模式保存的系统提示词发送给 API。不限于某个图像模型，也可用于视频、音乐等工作流的提示词生成。节点输出为文本，不直接生成图片、视频或音乐。

内置参考库提供以下任务模式，可复制到用户配置后编辑或删除：

- 通用 · 文生图
- 通用 · 图生图
- 通用 · 文生视频
- 通用 · 文生音乐
- Qwen Image 2.1 · 文生图
- Qwen Image 2.1 · 图生图
- FLUX.3 · 文生图
- MOSS-Image · 文生图
- 图像识别文生图洗图
- MiniMax H3 · T2VA · 文生音画视频
- MiniMax H3 · I2VA · 首帧生成音画视频
- MiniMax H3 · FL2VA · 首尾帧生成音画视频
- MiniMax H3 · L2VA · 末帧生成音画视频
- MiniMax H3 · Ref2VA · 全参考模式

FLUX.3 文生图模板保留英文原文，建议输出语言选择 **跟随模板**。需要指定画布比例时，可在输入开头添加 `TARGET CANVAS: W:H`，例如 `TARGET CANVAS: 16:9`。

MiniMax H3 模板依据官方 [h3-prompt-writing skill](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills/h3-prompt-writing) 的 [基础模式指南](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/base-en.txt) 和 [全参考指南](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/h3-prompt-writing/references/ref-en.txt) 按英文原文提取，保留原有规则和示例，不翻译正文；仅增加英文的当前任务模式说明。前四种模式使用三字段音画结构；Ref2VA 使用六字段结构，并包含基础指南中的共用镜头、对白与声音规则。建议将输出语言设为 **跟随模板**，按官方规则用英文描述，保留对白、歌词和画面文字的原文。时长请在输入提示词中说明。

I2VA 第一张图片是首帧；FL2VA 第一、二张图片分别是首帧和末帧；L2VA 第一张图片是末帧。Ref2VA 可基于图片或文字中的参考素材说明组织全参考提示词；当前节点没有视频、音频文件输入，不会实际读取这些文件。

MOSS-Image 模板整合官方 [moss-image-prompt-enhancer skill](https://github.com/OpenMOSS/MOSS-Image/tree/main/skills/moss-image-prompt-enhancer) 的主指南、Layout 参考、编译规则和校验案例，正文使用英文。非 JSON 输入默认输出纯文本 Caption，即使是海报或文字排版也不会自动转成 JSON；JSON 输入保留 JSON 输出，已有 Layout 按布局格式扩写。用户明确要求时可切换为纯文本或 JSON/Layout。建议输出语言选择 **跟随模板**。Layout 输出 JSON 不包含尺寸。可在输入中指定宽高（建议为 16 的倍数）；未提供时模板自行选择，已有居中坐标布局会推断内部画布并保留有效坐标，不会追问尺寸。模板会修正明显的元素分类、空文字和缺失描述；图像生成尺寸仍需在工作流中设置。 Layout 的元素位置仅由 bbox 表达，整体描述和元素描述不再重复左右、上下、居中等位置措辞；画面中实际需要显示的文字保留原文。当前为系统提示词适配，节点不会执行官方 Python 编译器，坐标由 API 模型计算，使用前应核对布局。

**图像识别文生图洗图** 需要连接参考图片，并使用支持图片输入的 API 模型。识别人物、物体、场景、构图、光线、色彩、材质、画风和可辨文字，输出可独立用于文生图的自然语言提示词；不输出坐标或 JSON。默认使用中文，遵循节点的输出语言设置。“多角度”指多个视觉描述维度，不会添加其他机位。 按画面复杂度分为简单、中等、复杂三级，针对产品静物、食品、动植物、建筑室内、风景、插画和图文设计等题材细描，一般画面输出最多 4000 字；密集文字逐块描述布局、大小与字号层级并完整转录可辨原文，必要时允许超出字数上限；只描述实际可见内容，使用正向画面陈述，不附加“没有、不要”等排除性规则。多图未指定用途时以第一张为主；可在输入中说明要修改的内容，其余细节保持参考图特征。

### 管理任务模式

1. 点击节点上的 **管理任务模式**，或从主菜单 **CDToolSets → 任务模式与系统提示词** 打开编辑器。
   顶部标签切换用户配置与内置参考库，左侧可搜索和选择任务模式，右侧查看或编辑提示词内容。
2. 在 **用户配置（实际运行）** 中修改已有模式，或点击 **新建**，填写名称和系统提示词。
3. 对于必须基于图片工作的模式，勾选 **必须提供参考图片**；其他模式可不连接图片。
4. 点击 **保存**，节点的任务模式下拉列表会同步更新。也可使用 **复制为新模式** 创建不同模型的模板。
5. 切换到 **内置参考库（只读）** 可查看系统模板。点击 **复制到用户配置** 创建可编辑的副本，再点击保存；若用户配置中已有同名模式，会自动给副本添加后缀。
6. 误删多个模式或需要初始化配置时，可在内置库点击 **添加缺少的内置模式**。只补充缺少的名称，不覆盖已有同名模式或自定义内容。

系统提示词原样保存，无需占位符，可包含换行、JSON 示例、歌词规则或其他输出格式要求。模式名称必须唯一。

### 节点参数

| 参数 | 说明 |
| --- | --- |
| 输入提示词 | 当前生成需求，作为用户消息发送；系统提示词从所选任务模式读取。 |
| 任务模式 | 选择已保存的系统提示词模板。可按模型、用途自行命名。 |
| 输出语言 | 中文、英文或跟随模板，默认跟随模板。选择“跟随模板”时不额外添加语言和格式要求；其他选项保留模板中的结构、JSON 键名及用户要求保留的原文。 |
| api_key | 默认 `local`；远程服务请填写实际密钥。 |
| api_base_url | 默认 `http://127.0.0.1:11434/v1`，支持基础地址或完整接口地址。 |
| API接口 | `/chat/completions`（默认）或 `/responses`。 |
| model | 默认 `qwen3.8-27b`，请填写所用服务实际提供的模型名称。 |
| 思考强度 | `none`（默认）、`low`、`medium`、`high`、`xhigh`、`max`；非 `none` 时自动开启思考。 |
| seed | 仅用于 ComfyUI 判断是否重新执行，不发送给 API。 |
| 图片 | 可选、自动扩展的参考图接口，最多展开 100 路。按接口序号发送，每路读取批次第一张图片；模型须支持图片输入。 |
| 提示词（输出） | `STRING` 文本，保留模板要求的输出格式，不自动提取或改写自定义 JSON 字段。 |

模板由插件目录下的两个 JSON 文件管理：

| 文件 | 用途 |
| --- | --- |
| `data/builtin_task_modes.json` | 随插件提供的只读参考库，管理界面和保存接口不会修改它。用于复制、恢复和初始化用户配置。 |
| `data/task_modes.json` | 通用节点实际运行时读取的用户配置，可以自由新建、修改和删除。首次运行且文件不存在时，从内置库复制一份并保存。 |

已有用户配置会原样保留，内置库更新不会自动覆盖或补回用户删除的模式。用户配置为空数组时保持为空，需主动复制或导入内置模板。同一 ComfyUI 安装共享用户配置，重启后保留；备份或迁移时请一并复制 `data/task_modes.json`。它不随工作流导出，也不会被 Git 跟踪；内置参考库随插件发布。

修改所选模式的系统提示词或参考图要求后，节点会重新计算，避免复用旧模板的执行缓存。重命名会同步更新当前页面中的节点选择；其他已保存工作流中的旧名称需要重新选择。删除模式后会从下拉列表移除；若节点正选中该模式，会提示重新选择，不会自动切换到另一种任务。

## 获取图片比例和像素数

读取 `image` 的宽高，推断最接近的官方比例；未连接图片时使用 `width` 和 `height`（默认均为 1024）。连接图片后，图片尺寸优先于数值输入。

节点位于 `CDToolSets/图像`，输出 `aspect_ratio`，可直接连接官方 **Resolution Selector（分辨率选择器）** 的同名输入。若选择器未显示该接口，可右键将 `aspect_ratio` 控件转换为输入。

直接复用官方选择器的比例选项，当前包括 1:1、2:3、3:2、3:4、4:3、9:16、16:9 和 21:9。按宽高比的对数距离选择最近项，使横图、竖图的相对偏差采用一致标准。节点只读取图片尺寸，不缩放或修改图片。

同时输出浮点数 `megapixels`，可连接官方分辨率选择器的同名参数。与官方计算方式一致，数值为 `width × height ÷ (1024 × 1024)`，例如 1024×1024 输出 1.0。连接图片时使用图片尺寸，否则使用数值输入。

## QwenImage2.1提示词增强(API)

将简短的画面需求整理为更完整的提示词，补充主体、构图、场景、光线、材质等视觉描述；图生图模式结合参考图片描述修改目标和需要保留的内容。

- 支持文生图与图生图两种任务模式。
- 支持最多 8 路参考图片输入。
- 支持中文和英文输出，要求画面文字、品牌名和专有名词保留原文。
- 支持 `/chat/completions` 和 `/responses` 两种 API 接口。
- 支持思考强度选择，并自动控制是否启用思考。
- 输出纯文本提示词，可连接到文本编码或文本显示节点。

### 参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 输入提示词 | 空 | 描述想生成的画面或对参考图片的修改要求。为空时直接输出空字符串。 |
| 任务模式 | 文生图 | 文生图用于扩写画面描述；图生图结合参考图片增强编辑指令，至少需要连接一张图片。 |
| 输出语言 | 中文 | 可选中文、英文。中文要求使用简体中文；画面中明确要求的文字、专有名词和品牌名保留原文。 |
| api_key | `local` | 所用 API 服务的密钥，必须填写。默认值用于本地服务，远程服务请填写实际密钥。 |
| api_base_url | `http://127.0.0.1:11434/v1` | API 服务地址，可根据所用服务修改，支持基础地址、以 `/v1` 结尾的地址或完整接口地址。 |
| API接口 | `/chat/completions` | 可选 `/chat/completions` 或 `/responses`，节点自动使用对应的请求格式。 |
| model | `qwen3.8-27b` | API 模型名称，以所用服务提供的名称为准。图生图需要使用支持图片输入的模型。 |
| 思考强度 | `none` | 可选 `none`、`low`、`medium`、`high`、`xhigh`、`max`。`none` 关闭思考，其余选项开启思考。 |
| seed | `0` | 仅用于 ComfyUI 判断是否重新执行节点，不发送给 API 后端。改变 seed 可触发重新生成；支持生成后固定、递增、递减或随机化。 |

### 图片输入与输出

| 接口 | 类型 | 说明 |
| --- | --- | --- |
| 图片、图片2～图片8 | `IMAGE` | 可选参考图片，仅图生图模式使用，按接口顺序发送。每个接口读取图片批次的第一张。 |
| 增强提示词 | `STRING` | 增强后的提示词文本，自动清理支持格式的思考块和代码块，并提取 JSON 回复中的 `rewritten_prompt`。 |

参考图片发送前会保持宽高比，将最长边超过 2048 像素的图片缩小到 2048 像素，并转换为 JPEG。

### 使用方法

**文生图**

1. 填写 `api_key`、`api_base_url` 和 `model`，选择服务支持的 API 接口。
2. 任务模式选择“文生图”，填写画面需求。
3. 选择输出语言和思考强度，将“增强提示词”连接到后续文本节点并执行。

输入示例：

> 一只橘猫坐在窗边，午后的阳光，温暖的生活摄影风格。

**图生图**

1. 任务模式选择“图生图”，使用支持图片输入的 API 模型。
2. 连接至少一张参考图片，可通过其他图片接口添加参考图。
3. 在输入提示词中说明修改目标、参考图的用途以及需要保留的内容。

输入示例：

> 保留图1人物的面部特征和服装，将背景替换为图2中的街道，调整为傍晚暖色光线。

### API 地址示例

以 `/chat/completions` 为例：

| api_base_url | 实际请求地址 |
| --- | --- |
| `https://api.example.com` | `https://api.example.com/v1/chat/completions` |
| `https://api.example.com/v1` | `https://api.example.com/v1/chat/completions` |
| `https://api.example.com/v1/responses` | `https://api.example.com/v1/chat/completions` |

选择 `/responses` 时使用对应路径；填写完整接口地址时，末尾接口路径会按当前选择替换。

### 使用说明

- API 服务及模型需支持所选接口，以及请求中的 `enable_thinking` 和 `reasoning_effort` 参数。各模型支持的思考强度可能不同。
- 最大输出 token 和上下文长度使用服务端默认设置。
- 节点执行时会将输入提示词发送到所填 API 地址，图生图还会发送参考图片。费用和数据处理方式以 API 服务商说明为准。
- 分享工作流前请清空 `api_key`。
